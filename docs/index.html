paperdiff

A paper vs code consistency checker for ML research. Give it an arXiv paper and its repository; it lists every place where the hyperparameters, data split, random seeds and training length in the paper differ from the code's configs, argparse defaults and README commands, with file:line on both sides.

GitHubExample reports

paperdiff only reports differences. It does not judge whether a paper is correct and never draws conclusions about authors. A difference can be a typo, a later code change, a documented choice, or an extraction error by the tool.

Try it

uv tool install git+https://github.com/majiayu000/paperdiff
paperdiff check 2305.18290 https://github.com/eric-mitchell/direct-preference-optimization -o out/

How it works

  • Reads the LaTeX source from export.arxiv.org (one request at a time, cached), PDF as a fallback: sentences and hyperparameter tables.
  • Reads the code without running it: argparse and absl flags, YAML and hydra configs, README and shell launch commands.
  • Compares each claim with the script its experiment uses, then classifies: conflict, ambiguous, missing, match.
  • Optional rerun of one or two numbers on your machine, only with --allow-run and a hard time limit.
